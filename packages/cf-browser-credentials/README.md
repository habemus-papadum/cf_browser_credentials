# @habemus-papadum/cf-browser-credentials

A TypeScript library for minting ephemeral credentials from a Cloudflare worker for an otherwise static site

## Install

```sh
npm install @habemus-papadum/cf-browser-credentials
```

## Usage

```ts
import { greet } from "@habemus-papadum/cf-browser-credentials";

greet("world"); // "Hello, world!"
```
